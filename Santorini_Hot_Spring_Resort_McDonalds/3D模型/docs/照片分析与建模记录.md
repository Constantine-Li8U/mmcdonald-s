# 照片分析与建模记录

## 证据范围

模型使用 `references/EXT_01_front.jpg` 至 `EXT_07_entrance_detail.jpg` 共 8 张用户提供照片。照片中可辨识的门店招牌、建筑名称和城市信息作为建模依据；树木、车辆、道路、旗帜、广告牌和人物仅作为环境参照，按规范排除。

## 可见构件

1. 白色仿圣托里尼 / 欧式地中海风格的主体建筑，横向展开，具有多个侧翼。
2. 中央三层拱券式钟楼 / 山墙，顶部悬挂铜钟；中层拱券内有两座人物雕像。
3. 中央立面可见“圣托利庄园”和 `SANTORINI HOT SPRING RESORT` 标识，以及金色麦当劳 M 标志。
4. 入口为四柱门廊，带白色 `McDonald's` 门头、竖向 `McCafé` 标识和蓝色穹顶 / 雨篷。
5. 两侧和侧翼为重复的高拱窗，窗框呈蓝色；左侧可见玻璃电梯 / 楼梯塔。
6. 立面存在暖色室内透光、金色标识和蓝色玻璃反射，预览采用三点柔光并另设门店暖色灯光。

## 尺寸与精度

主体宽 34.0 m、进深 18.0 m、主檐高 9.0 m、中央钟楼高 17.8 m；这些数值由照片比例和常见门厅尺度推定，未经过现场测绘。模型为 L1 视觉复原，背面、屋顶和照片不可见的连接处采用简化推定，并在对象元数据中标注 `photo_estimated=true`。

## 建模取舍

优先完成轮廓、层数、拱券、窗洞、入口、钟楼和招牌等 P0 特征；拱窗框、柱、穹顶、门廊和台阶作为 P1 细节；室内家具、菜单、人物、车辆与环境景观按规范省略。材质通过粗糙度、金属度、玻璃反射和低强度自发光表现表面差异，不使用未经照片支持的装饰。
