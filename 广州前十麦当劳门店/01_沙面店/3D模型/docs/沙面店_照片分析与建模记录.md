# 麦当劳沙面店｜照片分析与建模记录

## 1. 项目范围

- **唯一对象**：麦当劳（沙面店），广州荔湾区沙面大街 54 号胜利宾馆首层北面厅，临街面朝沙面三街一侧。
- **视觉依据**：本店档案中的 `EXT_01–05`、`SIGN_01–04`、`CNT_01–02`、`ENV_01` 实拍。
- **模型范围**：门店临街立面及其所在的简化为三层宿主建筑体量。首层为麦当劳，拱层与上层属于宿主建筑表达，不推断其内部经营用途。
- **明确排除**：人物、车辆、树木、道路、河道、护栏、隔离桩、周边建筑、购物车、互联网图标、全息构件和装饰性地台。
- **精度性质**：照片推定比例的建筑可视化模型，**不是实测、测绘或施工模型**。

## 3. 形态与比例判读

### 3.1 建筑轮廓

- 照片显示的是**历史建筑中的一段临街立面**，并非独立西式小楼。
- 可见三个高度层级：首层商业立面、半圆拱所在层、上部矩形窗所在层。
- 宽景照片可辨四个连续半圆拱；近景照片只覆盖其中一部分，不能用单张近景推断全宽。
- 为保证模型独立完整，补入进深、侧墙、后墙、楼板与平屋顶；这些仅用于体量闭合，不增加无依据的立面装饰。

### 3.2 尺寸基准

以双扇玻璃门的常规门高约 2.4 m 为视觉标尺，再按立面构件比例推定：

| 项目 | 模型采用值 | 性质 |
| --- | ---: | --- |
| 建筑总宽 | 18.0 m | 推定 |
| 建筑进深 | 6.5 m | 简化补全 |
| 主体高度 | 10.2 m | 推定 |
| 首层结构顶 | 4.15 m | 推定 |
| 拱层结构顶 | 7.45 m | 推定 |
| 单拱宽 | 3.55 m | 推定 |
| 落地 M 高 / 宽 | 2.62 / 2.72 m | 推定 |
| 玻璃入口宽 | 2.05 m | 推定 |
| 屋顶 | 平屋顶 + 低女儿墙 | 不可见区域简化 |

这些值服务于**视觉比例协调**，不得反向当作真实建筑尺寸引用。

## 4. 构件级取舍

### 保留并细建

1. **浅灰石材立面**：水平分缝、窗下墙、拱间墙、层间线脚。
2. **四个半圆拱**：真实开洞、深色后退玻璃、圆角石质拱圈与窗台。
3. **首层五个开间**：甜品站、两樘主展示窗、玻璃入口、右侧展示窗。
4. **黑色窗篷**：矩形体块、轻微圆角、白色 McDonald's 字。
5. **落地金色 M**：独立有厚度的单体网格，不用两根圆管拼凑，不悬浮。
6. **入口**：双扇门、中梃、拉手、门槛和三级台阶。
7. **品牌字**：上层 McDonald's、竖向 McCafé、甜品站中文字。
8. **上层窗**：矩形深色玻璃、细分窗框、克制的竖向分缝。

### 合理简化

- 石材不做高成本雕刻与风化污渍，仅以分缝、线脚和色差表达。
- 室内仅保留暖色背板、玻璃纵深和少量灯管，不重建家具、人物或商品。
- 背立面与侧面为无装饰实墙，不虚构照片未展示的门窗。
- 屋顶按平屋顶处理，不增加设备、水箱、栏杆或造型。
- 门贴、海报、菜单、花盆等时效性内容不进入永久建筑模型。

## 6. 光照与镜头

- 使用中性建筑可视化呈现：大面积主光、弱冷色补光、柔和顶部轮廓光。
- 预览地面只存在于 `90_PREVIEW_STUDIO_EXCLUDED_FROM_EXPORT`，**不导出到模型文件**。
- 正立面镜头：检查开间、拱和招牌位置。
- 三分之四镜头：检查完整体量、进深、屋顶和首层外挑构件。
- 首层细节镜头：检查 M、黑色窗篷、门和台阶。
- 采用 AgX 色彩管理与降噪，避免高饱和、强泛光、全息边缘和夸张景深。

## 7. 参数化与可编辑性

- `src/shamian_config.json`：面宽、进深、层高、拱宽、开间位置、M 尺寸与色值。
- `src/build_shamian.py`：按语义函数建立墙体、拱洞、门窗、招牌、台阶与预览灯光。
- `.blend`：`01–06` 为建筑本体集合，`90` 为预览专用，`99` 为参考元数据。
- `.blend` 内招牌文字保持可编辑；导出 GLB/OBJ/FBX 时转为网格，避免跨软件缺字。
- 对象自定义属性记录 `visual_evidence` 与 `photo_estimated`，便于追溯依据。

## 8. 制作过程记录

1. 逐张判读 12 张本店照片，先用宽景确定拱数，再用近景校正构件。
2. 区分“照片可见”与“不可见补全”，建立推定尺寸表。
3. 自动图生 3D 仅作辅助探索；因远程参考图读取失败，没有形成可用结果，也未纳入交付。
4. 改用参数化精确建模，建立真实拱洞、门窗、落地 M 与完整建筑壳体。
5. 导出 BLEND、GLB、OBJ、FBX，渲染三个固定视角，并检查跨格式文件。
6. 将本次取舍沉淀为《系列门店建模风格规范》，后续门店只替换照片依据与参数，不改变系列标准。

## 9. 使用边界

- 可用于门店档案、建筑展示、系列视觉研究和后续美术修改。
- 不用于施工、改造报价、结构计算、消防、精确定位或任何需要实测尺寸的场景。
- 品牌标识仅用于还原该真实门店，不代表品牌授权或官方模型。
- 参考照片版权归原作者与品牌方所有；模型为基于照片的建筑可视化重建。
