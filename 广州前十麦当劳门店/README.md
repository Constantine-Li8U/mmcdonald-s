## 每个门店文件夹里有什么

- `NN_门店名.md` / `NN_门店名.docx`：说明文档，含基本信息表、得分卡、面积座位、正负风评、实拍、照片来源链接
- `photos/`：该店实拍照片，命名规则 `序号_简称_角度_序号.jpg`
- `photos/_sources.csv`：每张图的平台、来源页、抓取时间、版权说明

## 角度代码

| 代码 | 含义 |
| --- | --- |
| EXT | 外立面 / 门头 |
| CNT | 点餐前台 / 甜品站 |
| SEAT | 座位区 / 堂食区 |
| KID | 儿童区 / 游乐区 |
| SIGN | 招牌细节 / 品牌元素 |
| ENV | 周边环境 |

## 照片核对

- `照片核对报告.md` / `.docx`：逐店照片核对结论、清晰度核查、仍无法补充照片的门店及原因
- `_数据与评分/照片覆盖核对表.csv`：10 家门店逐行的照片数 / 角度 / 清晰度 / 核验结论
- `_数据与评分/照片审计.json`：每张图的宽高、体积、锐度、哈希
- `_数据与评分/候选图/`：采集到的候选与弃用留档（含原始标题、图片直链）

## 支撑材料

- `_数据与评分/候选池评分明细.csv` — 42 家候选门店逐项打分
- `_数据与评分/榜单原始抓取_20261024.json` — 8 个高德榜的原始解析结果
