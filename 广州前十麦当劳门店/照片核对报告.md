## 四、收录与排除规则

1. **只要门店空间照**：外立面 / 门头 / 点餐前台 / 座位区 / 儿童区 / 招牌 / 周边，菜品与包装特写一律不收。
2. **必须能确认是本店**：店名精确匹配（如「麦当劳(总统大酒店店)」）或画面可读到本店专属标识（水印、商场招牌、下沉楼梯等）。判不准的按弃用处理。
3. **异地同名店一律排除**：上海江湾镇店、上海唐镇阳光城店、合肥恒生阳光城店、佛山江湾三路店、郑州东风路店、北京丽都／复兴门店等。
4. **不放示意图 / 占位图 / AI 生成图**，缺就写缺。
5. 图片仅作个人研究与非商业展示，版权归原作者；每张图的平台、来源页、原始直链记在各店 `photos/_sources.csv`。
