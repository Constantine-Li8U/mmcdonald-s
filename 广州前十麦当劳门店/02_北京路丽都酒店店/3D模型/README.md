# 麦当劳（北京路丽都酒店店）｜3D 建筑模型（含灯光）

**系列第 2 号模型 · 灯光增强版** — 在沙面店确立的系列规范基础上，首次加入**按实拍还原的门店灯光**。

## 这个模型是什么

- 以 `../photos/` 内 12 张已核验实拍为唯一视觉依据的参数化建筑模型。
- 范围：**丽都大酒店裙楼的一、二层**（麦当劳使用的部分）。酒店塔楼在照片中不可辨，**未建模**。
- 含**日景 / 夜景两种灯光状态**：夜景只保留门店自己的灯（发光招牌、雨篷筒灯、室内暖光、甜品站灯箱），与 EXT_01 夜景实拍对应。
- 无人物、车辆、街道、排队人群、海报贴图或无关装饰。

## 灯光一览（每处都有照片依据）

| 灯光元素 | 照片依据 | 实现方式 |
| --- | --- | --- |
| 黑色面板上的发光金色 M | EXT_01（夜）/ EXT_02、03（昼） | 自发光材质 + 面板暖色洗墙灯 |
| 入口上方红色发光招牌盒 | EXT_01、EXT_02 | 红色自发光盒体 + 发光 M |

| McCafé 白色发光字（木质格栅墙、右侧竖招牌） | EXT_01、02、03 | 低强度自发光 |
| 一层 / 二层室内暖光 | CNT_01..03、SEAT_01..04 | 暖色自发光背板 + 面光源 |
| 丽都酒店名称字（右侧暗墙） | EXT_01 | 低强度暖色自发光 |

## 日 / 夜切换方法

在 Blender 中：

- **夜景**：显示 `07_LIGHTING_STORE`，隐藏 `90_PREVIEW_STUDIO_EXCLUDED_FROM_EXPORT` 中的灯光，世界背景调暗。
- **日景**：反之。脚本内 `set_day()` / `set_night()` 即此逻辑。
